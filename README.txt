ホームページ更新用ファイル

1. ZIPを展開してください。
2. index.html、index-ja.html、site.css、favicon-rino.svg の4ファイルを、
   clone済みの etsurin.github.io フォルダ直下へコピーしてください。
   同名のHTMLは上書きします。現在のファイルは必要に応じてバックアップしてください。
3. index.html をブラウザで開いて確認してください。
4. 公開する際はリポジトリで変更内容を確認して、commit / pushしてください。

index.html    : 英語版
index-ja.html : 日本語版
site.css      : 共通スタイル
favicon-rino.svg   : タブ用アイコン

EN / JP リンクで言語を切り替えます。
既存の assets フォルダに依存しません。
Google Fontsが利用できない場合は端末のフォントで表示します。
JavaScriptやビルド作業は不要です。
